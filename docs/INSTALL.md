# INSTALL

## Supported Platforms (v1)
- Windows
- macOS
- Linux

## Installer Strategy

### Development (now)
- Use source-based setup via `docs/DEVELOPMENT.md`

### Public Beta (later)
- Windows installer (signed)
- macOS notarized app bundle
- Linux AppImage + distro packages (as feasible)

## Principle

Keep setup simple enough that a first-time open-source contributor can run AI-OS quickly.
