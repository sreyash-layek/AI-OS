# CONTRIBUTING

Thanks for helping build AI-OS ✨

## First-time Contributors Welcome
This is a beginner-friendly open-source project. Clear docs and friendly reviews are a priority.

## How to Contribute
1. Fork the repo
2. Create a feature branch
3. Make changes with docs/tests where applicable
4. Open a PR using the template

## Ground Rules
- Keep changes focused
- Respect privacy/safety architecture
- Prefer local-first implementations
- Update docs for behavior changes
